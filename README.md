# Addis Cafe

A static Ethiopian café menu built with React and Vite.

## Technologies

- React
- Vite
- JSX
- CSS

## Features

- Reusable React components
- Props
- JSX expressions
- map()
- React keys 
- Responsive CSS Grid
- Category-specific styling
- Hover effects
- Footer

## Components

- `App.jsx` — Main application component
- `Header.jsx` — Cafe name, description, and location
- `Menu.jsx` — Menu data and list rendering
- `MenuItem.jsx` — Reusable menu item component
- `Footer.jsx` — Footer section

## How to Run

npm install
npm run dev
